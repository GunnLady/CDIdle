# Resource icons v1

Five standalone resource illustrations for the desktop header, generated as
high-resolution square raster assets over a uniform `#00ffff` chroma-key
background, then converted to transparent PNGs.

Shared direction: polished hand-painted medieval-fantasy game UI, compact and
readable silhouette, dimensional materials, controlled highlights, no frame,
text, tool, ground, external shadow, pixel art, or baked functional content.

- Gold: antique coins, with the established rampant lion on the main coin.
- Food: a large caramelized roast-meat haunch with a prominent ivory bone.
- Wood: three dark bark-covered trunks supporting one honey-colored squared
  construction beam placed diagonally.
- Stone: three dressed cool blue-gray granite blocks and one rough foreground
  shard.
- Ore: four irregular dark iron-ore chunks with silver-steel fractured faces
  and subtle non-emissive violet veins.
- Separator: one very simple upright amethyst diamond with broad facets and a
  thin aged-brass rim, designed for a 12 x 16 px desktop display.

Runtime contract: artwork is decorative; labels and resource values remain DOM
content. Version 1 is displayed only at the desktop `xl` breakpoint while the
existing compact icons remain active on tablet and mobile.
