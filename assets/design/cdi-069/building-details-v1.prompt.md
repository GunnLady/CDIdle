# Building details v1 — prompt contract

Use case: stylized-concept
Asset type: panoramic game UI building-detail illustration
Input images: Image 1 is the strict edit target and visual anchor.
Primary request: preserve the recognizable building, materials, palette,
lighting, atmosphere, painterly texture and camera direction. Pull the camera
substantially farther back and continue the existing environment naturally to
the right.
Composition: the generated 2:1 canvas is center-cropped vertically to 4:1.
Keep the complete principal subject inside the central 45% of the canvas
height and inside the leftmost 24% of its width. Add crop-safe sky above and
foreground below. Continue the environment across the right 76%, becoming
naturally darker and quieter toward the far right for DOM-rendered UI copy.
Constraints: no redesign, duplicate focal subject, new focal structure,
characters, seams, mirroring, flat empty gradient, text, icons, UI, frame,
border, logo or watermark.

Each building keeps the biome, weather, architecture and light established by
its corresponding `building-card-*-v1.jpg` edit target.

Exception: `academie` replaces the incoherent church-like source facade with a
structurally plausible compact stone-and-timber runic workshop. It retains the
night palette, restrained violet craft glow and painterly rendering, with one
complete roof, a masonry chimney and a believable open work bay.
Its `1024 x 448 px` menu card is derived from this same master to keep both
views architecturally identical.

The `poste_chasse` panorama uses a downward crop offset of 80 source pixels so
the hunting lodge and forest floor sit near the visual center instead of being
pressed against the lower frame.
