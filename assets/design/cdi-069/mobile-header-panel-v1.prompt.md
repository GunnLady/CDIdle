# Mobile header panel v1

Built-in ImageGen generation using the approved desktop wood rail and ornaments as material references.

Create one thick, self-contained horizontal walnut panel for a phone header, with a clean antique-gold and dark-iron rim on all four edges. Keep a broad empty central wood area for DOM-rendered content. Integrate only tiny symmetrical end ornaments: one small violet gem, short gold/iron curls, and restrained leaf accents per side. No text, numbers, resource icons, buttons, crest, shield, crown, weapons, long vines, cast shadow, watermark, pixel art, or HD-pixel treatment.

Generation backdrop: flat `#00ffff` chroma key. The final PNG uses a locally removed soft alpha matte and is cropped to the panel bounds.
